# 🎮 XO Arena

> A modern multiplayer Tic-Tac-Toe game built for fast, competitive head-to-head matches.

XO Arena is a responsive **2-player Tic-Tac-Toe web application** where players can compete on the same device, track scores, and review their complete game history.

## ✨ Features

* 🎯 **2-Player Local Multiplayer**
* ❌⭕ Player X vs Player O
* 🏆 Automatic win and draw detection
* 📊 Live scoreboard
* 📜 Complete game history
* 💾 Persistent game records using LocalStorage
* 🌓 Dark/Light theme
* 📱 Responsive design for desktop, tablet, and mobile
* ✨ Smooth animations and interactive UI
* 🗑️ Delete individual records or clear game history
* 🔄 Start new matches instantly

## 🎮 How to Play

1. Enter Player 1 and Player 2 names.
2. Click **Start Match**.
3. Player X makes the first move.
4. Players take turns placing their symbols.
5. The first player to get three symbols in a row wins.
6. If all cells are filled without a winner, the match ends in a draw.
7. The result is automatically saved to game history.

## 📊 Score & History

XO Arena keeps track of completed matches, including:

* Player names
* Winner
* Draws
* Number of games played
* Date and time
* Match results

All records are stored locally in the browser using **LocalStorage**, so the data remains available after refreshing the page.
